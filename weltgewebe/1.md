The verification command curl -k https://leitstand.lan/ will fail unless leitstand.lan resolves to the bind address (often 127.0.0.1 in this setup). Since the text mentions "via curl-Resolve", the example should include a --resolve leitstand.lan:443:127.0.0.1 (or whatever CADDY_BIND is) so it works without local DNS changes.

Suggested change
curl -k https://leitstand.lan/
curl -k --resolve leitstand.lan:443:127.0.0.1 https://leitstand.lan/

The new leitstand.lan site is added to the production Caddyfile unconditionally. On non-heimserver deployments (e.g. VPS) this creates an extra vhost that will still accept requests and likely return 502 (and tls internal will manage an internal CA unnecessarily). Consider moving this block into a heimserver-only Caddyfile/override (e.g. mounted via compose.heimserver.override.yml) or otherwise ensuring it’s only enabled when the heimnet upstream is present.

+## 10. Heimserver-Policy
+
+Für den Betrieb auf einem Heimserver (z. B. hinter einer Firewall oder in einem lokalen Netzwerk) gilt ein striktes **Gateway-Prinzip**.
+
+### Grundsätze
+
+1. **Gateway-Only Entry:**
+   Nur der Caddy-Container darf Ports auf dem Host veröffentlichen.
+   Alle anderen Services (API, DB, Upstreams) müssen isoliert bleiben.
+
+2. **Loopback Binding:**
+   Ports werden standardmäßig auf `127.0.0.1` ("eingesperrt") gebunden, um versehentliche Exponierung im LAN/WAN
+   zu verhindern.
+
+3. **Shared Network (Upstreams):**
+   Lokale Upstream-Dienste (z. B. Leitstand) werden über ein dediziertes Docker-Netzwerk (`heimnet`) angebunden,
+   nicht über Host-Ports.
+
+### Einrichtung
+
+1. **Netzwerk erstellen:**
+
+   ```bash
+   docker network create heimnet
+   ```
+
+2. **Bind-Adresse setzen:**
+   Setze `CADDY_BIND=127.0.0.1` in deiner `.env`-Datei oder im Environment.
+   Ohne diese Variable lauscht Caddy auf `0.0.0.0` (Standard).
+
+3. **Start mit Override:**
+   Nutze die `compose.heimserver.override.yml`, um das Netzwerk anzubinden:
+
+   ```bash
+   CADDY_BIND=127.0.0.1 docker compose \
+     -f infra/compose/compose.prod.yml \
+     -f infra/compose/compose.heimserver.override.yml \
+     up -d
+   ```
+
+### Verifikation
+
+Prüfe, ob nur lokale Ports offen sind:
+
+```bash
+ss -lntp | grep -E ":(80|443)"
+# Erwartet: 127.0.0.1:80, 127.0.0.1:443
+```
+
